# AgenticPay: Autonomous AI Agent for Contextual Payments & Checkout

## Overview
AgenticPay is an AI-driven agent designed to streamline conversational commerce and automated payments using Razorpay infrastructure.

## Key Features
- Intent Recognition for Automated Purchasing
- Seamless Razorpay Gateway Integration
- Autonomous Invoice & Payment Link Generation

## Tech Stack
- Python / FastAPI
- LangChain / OpenAI API
- Streamlit / React (Frontend)
